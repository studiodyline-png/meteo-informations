Politique de confidentialité

Météo Flandres Françaises

Dernière mise à jour : 15 novembre 2026

1. Présentation

Cette application permet de générer et de publier automatiquement des prévisions météorologiques sur la page Facebook Météo Flandres Françaises.

2. Données utilisées

L'application utilise des données météorologiques provenant du service Open-Meteo pour préparer les bulletins météo.

Elle utilise également l'API Graph de Meta pour publier les bulletins sur la page Facebook.

L'application ne cherche pas à collecter les données personnelles des visiteurs de la page Facebook.

3. Stockage et sécurité

Les identifiants nécessaires à la publication Facebook sont conservés dans les secrets GitHub Actions et ne sont pas intégrés publiquement dans le code source.

Le programme utilise GitHub Actions pour exécuter automatiquement les tâches de publication.

4. Partage des données

Les prévisions publiées sont accessibles aux visiteurs de la page Facebook. Les services Open-Meteo, GitHub et Meta interviennent dans le fonctionnement technique de l'application, selon leurs propres politiques de confidentialité.

5. Suppression des données

Pour toute demande concernant les données liées à cette application, vous pouvez contacter son responsable à l'adresse : loljoo@hotmail.fr

6. Contact

Pour toute question concernant cette politique de confidentialité, vous pouvez contacter le responsable de Météo Flandres Françaises à l'adresse indiquée ci-dessus.
